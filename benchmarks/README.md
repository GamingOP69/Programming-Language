# Samrat Benchmark Suite

This directory contains benchmark scripts to measure compiler and runtime performance.

## Benchmark Metrics
1. **Compilation Time**: Time taken to parse, analyze, and build native object/binary executable.
2. **Binary Executable Size**: Size of output object/executable.
3. **Execution Throughput**: Runtime execution speed for CPU-intensive loops and numeric computations.

## Usage
Run benchmarks via Python runner:
```bash
python3 benchmarks/run_benchmarks.py
```
